# Dense piano speech examples

These are the selected fixed-Grand-Piano MIDI reconstructions from the [dense ASR experiment](../../../experiments/DENSE_ASR.md). Source speech is in the parent directory. No speech audio is mixed into the reconstructions.

Open [index.html](index.html) locally for offline playback; reveal the transcript only after listening. Each output has a 0.5-second release tail.
